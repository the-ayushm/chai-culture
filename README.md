# Royal Chai — Coming Soon Landing Page ☕👑

A premium “Coming Soon” landing page built for **Chai Culture**, inspired by the royal tradition of Indian chai.  
This project was created as part of the frontend developer assignment to design a visually rich, responsive, and brand-aligned digital experience.

---

## 🌟 Brand Concept

**Tagline:** Brew the Royal Tradition  
**Product:** Premium instant chai tea premix inspired by royal Indian households  
**Design Theme:** Royal, elegant, warm tones (gold, deep brown, cream)

The goal was to create a landing page that feels luxurious, culturally rooted, and modern — reflecting heritage and authenticity through design and interaction.

## 🎨 Design Choices (Assignment Requirement)

I designed the landing page with royal Indian aesthetics using deep brown and gold tones to convey warmth, heritage, and premium quality. Elegant serif typography was chosen to reflect tradition, while subtle animations and glow effects add a modern, luxurious feel. The layout is fully responsive to ensure a smooth experience across all devices.

---

## 🧩 Features

- Premium royal-themed UI
- Responsive layout (mobile-first)
- Animated hero and section reveals
- Countdown timer for product launch
- Email signup with validation alert
- Social media icon interactions
- Smooth micro-interactions with Framer Motion

---

## 🛠️ Tech Stack

- React (Vite)
- Tailwind CSS v4
- Framer Motion
- JavaScript (ES6)
- Google Fonts (Playfair Display, Cormorant Garamond)
